Upload Tips Recommended

Prepare a Lightweight Submission Package

Large files are not recommended for direct upload. For model checkpoints and other large assets, please provide a downloadable link in the external resources field. Package the remaining files into a single zip archive before uploading.

Submission Checklist

  • Trained model / model checkpoints

    Large model files are better provided as downloadable links instead of direct upload.

  • Inference code

    Inference code should be directly executable on the official evaluation set.

  • Runtime environment configuration

    Provide a Dockerfile, environment.yml, installation script, or equivalent runtime setup.

  • System description document

    Describe model architecture, training data, inference procedure, parameter scale, and external resources used.

  • Inference dependencies

    Package code, configs, documents, and other smaller files together into a single zip archive.
